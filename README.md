# One-Line Pitch — A Day of One-Line Pitches

Entry for the make.fun competition "A Day of One-Line Pitches"
(`u-ronigrv-a-day-of-one-line-pitches-12cd9bb3`).

The program writes one sentence — a pitch that would convince a friend
who has never coded to let an AI agent build their first app idea on
make.fun — to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

Then read `/output/entry.txt`. The sentence is at most 240 characters.
